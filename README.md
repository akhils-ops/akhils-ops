# akhils-ops

A multi-disciplinary repository for geospatial, academic, gaming, and shared library projects.

## 📋 Navigation

### 🌍 [GIS](./GIS)
Geospatial processing engine and location-based data tools.

### 📑 [LLR](./LLR)
PV (Photovoltaic) Literature review collection and research materials.

### 📊 [JIRA](./JIRA)
JIRA insights, dashboards, and analytics tools.

### 🎮 [Games](./Games)
Game development projects and interactive applications.

### 📚 [Shared](./Shared)
Shared libraries, utilities, and common modules used across projects.
